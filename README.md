# Kandoo Shoes

یک وب‌سایت فروشگاهی مدرن و شیک برای برند کفش `Kandoo` با طراحی ریسپانسیو، صفحه اصلی حرفه‌ای و تجربه کاربری جذاب.

## ویژگی‌ها
- صفحه اصلی زیبا و مدرن
- مجموعه‌های مختلف محصولات
- فیلتر محصولات بر اساس دسته‌بندی
- دکمه افزودن به سبد خرید
- منوی موبایل ریسپانسیو
- فرم عضویت در خبرنامه

## اجرا
برای اجرا، فایل `index.html` را در مرورگر باز کنید.

اگر خواستید، در مرحله بعدی می‌توانم نسخه‌ی React/Next.js و یا نسخه‌ی کامل‌تر فروشگاهی را هم برای شما بسازم.
